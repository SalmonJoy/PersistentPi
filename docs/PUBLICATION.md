# Public Snapshot and Disclosure Boundary

This independent public snapshot derives from private source commit
`5420476a67a91224287b5c16d6932c106d3a9e2e`. The original repository, scientific
records, hashes and historical tags remain unchanged. Its Git directory, commit
objects, tags and historical archives were not copied.

Safe copied source can naturally have the same content-addressed blob hash as
the private version. This is not imported Git history. Independence is established
by a new parentless commit, no original commits/tags, no alternates, and an audited
public tree. Private commit identifiers in methodology are provenance only.

## Included Material

The framework source, interfaces, SQLite migrations, protocols and public
scientific excerpts are distributed. `PUBLICATION.json` classifies source paths
as PUBLIC_SAFE or PUBLIC_REDACTED and records safe-file hashes. The full excluded
path inventory and original operational audit are retained privately.

Public report excerpts preserve outcomes and limitations, but omit source-bearing
examples, task-level tables, private account observations and raw reproduction
procedures. Some descriptions refer to evidence retained privately; absent paths
are not fabricated replacement evidence. Older reports' historical tags and hashes
identify the private scientific record, not public Git refs.

## Deliberate Code Differences

Private constructors in `m08/benchmark.py`, `control_suite.py` and
`orchestration_suite.py` are replaced by explicit fail-closed interfaces.
`m09/cohorts.py` retains task serialization, manifest/partition logic and access
gating, but not task-generating recipes or cohort instances. The family/tier names
are methodological metadata, not answers. No constructor reconstructs the withheld
evaluation tasks. No supplied private fixture or hidden/reference payload is copied.

Historical milestone freeze/parity functions still describe their real contracts.
They require evidence not distributed here and must not be treated as runnable
certification of the original studies. The public checkout does not authorize
admission probes, future feasibility inference or research launch commands.

## Distributed Tests

`tests/test_m010_offline.py` is the public subset of the historical offline
interface tests, not a hidden benchmark. Two methods are excluded explicitly:

- `test_f0_historical_parity`: requires original private responses/export.
- `test_prepare_and_seal_require_full_regression`: requires the private freeze/parity evidence.

Historical fixtures, source-bearing tests and cohort-coupled regression suites are
not distributed. Their excluded status is not a public PASS. Tests retained here
exercise mutation legality, representation, compiler limits, one-shot receipts,
paired scheduling, accounting, exact analysis and recording-stub export/replay.
Synthetic protocol scenarios and responses are explicitly synthetic, not original
coding tasks or substitutes for held-out tests. Newly generated offline receipts
are excluded from Git and do not become research outcomes.

## Private Evidence

Qualification48, Final96, all hidden/reference cases, protected archives, raw
research databases, source-bearing model traces, machine inventories and account,
billing, credential/authentication evidence are intentionally unavailable publicly.
Operational admission outcomes, model identity, request counts and aggregate costs
are scientific metadata. They do not disclose account entitlement/balance records.

The complete private audit and publication linkage are retained locally outside
the frozen source tree. No original historical tag is pushed to GitHub.
