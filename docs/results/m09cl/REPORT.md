## Implemented

The historical preflight failed at three blockers: offline-only adapter guards,
historical GLM request rendering, and automatic qualification continuation.
Historical files, scientific configuration and evidence are unchanged.

Seven additive files implement an explicitly admitted native transport and
renderer, a search-only store/capability/scheduler, the fixed laptop Runner
transport, separate CLI commands, and synthetic acceptance tests. Existing
scaffold catalog, references, ranking, gates, disclosure, resource accounting,
Screen8/Remaining24 union, supervisor and public verification are reused.

Live capability is disabled by default. Exact configuration/admission hashes,
observable identity and parameter mapping are required. No arbitrary adapter,
model override or fallback is accepted. The actual outbound API model is
**gpt-oss:120b**, derived from admission; **glm-5.3 is absent** from the stored
synthetic outbound dry run. Historical GLM rendering remains unchanged.

Qualification task material is never loaded by the search-only launcher;
only its frozen manifest is available. Non-search material, stage and result
requests are denied. All search terminal states close access permanently.
There is no final/hidden evaluator capability or continuation flag.
