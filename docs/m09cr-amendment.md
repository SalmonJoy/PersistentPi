## Credential And Account Prerequisites

Require newly rotated credentials through the dedicated environment/secret
mechanism, with rotation established independently of key presence. Revoke the
previous credential privately. Do not deliver a replacement through prompts,
repository files or command-line literals. Before authentication, synthetic tests
and actual-secret exclusion checks must cover artifacts, SQLite, reports,
exports, prompts, response/request logs and exception handling. Record only
presence/rotation metadata. Credentials are never copied to research processes.

Use authenticated non-generating model/account evidence first. Establish exact
model free entitlement, available included allowance, and either zero purchased
balance or an authoritative control preventing purchased-credit consumption.
Public catalog presence, user assertion and key presence alone do not prove these.
No purchase or account billing change is allowed. If mandatory prerequisites
cannot be established, stop BLOCKED without inference.

## Single Operational Probe

If prerequisites pass but probe-resolvable behavior remains unknown, freeze one
secret-free request with only this user message:

`Reply with the single word READY.`

Use the admitted model mapping, temperature 0, high thinking, seed 42 if supported,
128 generated tokens, non-streaming, 180 seconds and 65536 response bytes. No
system prompt, tools, attachments, conversation or PersistentPi/scaffold/task
content is included. Disable automatic retries and resending redirects. Freeze
the exact request hash before transmission; reserve resources and mark STARTED
durably first. A started/unresolved probe is never resent after restart. The
opportunity is consumed once transmission begins, including provider errors.

The response can establish authentication, entitlement, returned identity, usage,
thinking fields, supported parameter handling and termination/error metadata.
Parameter acceptance alone does not prove semantic enforcement; authoritative
model-specific evidence is required. A supported output-limit termination can
pass. The final answer need not equal READY. Indeterminate/missing contracts
produce BLOCKED_AFTER_PROBE, with no alternate prompt, larger cap or second probe.

Record exact secret-free request/response, thinking/final content, hashes, identity,
configuration, usage, cached count, latency, termination and validation outcome in
operational provenance. Exclude all probe data from Planner search. Probe
expenditure is separate from the eight proposal slots and 200000 proposal tokens;
include it in combined operational totals, without granting research allowance.

## States And Stop

- BLOCKED: missing credential/account prerequisite or non-probe-resolvable contract.
- READY_FOR_ADMISSION_PROBE: prerequisites pass, frozen probe not yet executed.
- ADMITTED: all mandatory checks pass from metadata or the single probe.
- BLOCKED_AFTER_PROBE: a sent probe fails or leaves a mandatory check unresolved.

Do not probe if metadata already establishes admission. ADMITTED still ends this
task; future search needs separate authorization and all existing campaign gates.
